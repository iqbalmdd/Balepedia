# Balepedia

Balepedia adalah website e-commerce modern yang menerapkan berbagai konsep **useful & advanced** yang digunakan dalam aplikasi real-world. Proyek ini merupakan bagian dari portofolio saya dan dibangun dengan teknologi terkini untuk memberikan pengalaman belanja online yang interaktif dan responsif.

## ✨ Fitur Utama

### 🔹 **Product Page**
- Menampilkan seluruh produk dengan **infinite scroll**.
- Filter produk berdasarkan kategori.
- Sorting produk berdasarkan harga.
- Routing yang optimal untuk pengalaman pengguna yang mulus.

### 🔹 **Product Detail Page**
- Menampilkan informasi produk lengkap.
- **Image selector** untuk memilih gambar produk.
- Menambahkan jumlah produk yang ingin dibeli.
- Tombol **Add to Cart** untuk memasukkan produk ke keranjang belanja.

### 🔹 **Cart Page**
- Menampilkan semua produk yang telah ditambahkan ke keranjang.
- Menampilkan total harga belanja.
- Opsi untuk mengupdate jumlah produk atau menghapus produk dari keranjang.

### 🔹 **My Order Page**
- Menampilkan daftar semua barang yang telah dibeli.
- Riwayat pembelian untuk pengguna.

### 🔹 **Authentication (Signup & Login)**
- Form registrasi dan login yang telah divalidasi menggunakan **Zod**.
- Keamanan data pengguna dengan sistem autentikasi modern.

## 🚀 Teknologi yang Digunakan
- **Frontend:** ReactJS, React Router, CSS
- **State Management:** Redux Toolkit
- **Validation:** Zod
